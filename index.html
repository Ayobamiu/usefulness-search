Xtract

Search for AI agents that tells the agent how useful each page is, and what it costs, before the agent reads it. It also flags pages that later news has replaced, so the agent does not repeat an old story as current.

Get a key

Free, 50 searches a day. The key is shown once; we store only a hash of it.




Search


curl -s "ORIGIN/v1/search?q=Humane+AI+Pin" \
  -H "Authorization: Bearer YOUR_KEY"


Each result has url, title, snippet, keenable_rank,
usefulness (0 to 1), price_cents (prices are simulated for now),
is_new (no usage history yet) and superseded_by (null, or the later page and event).
scoring_cost_usd is what our own model calls cost to score this search, at list prices.

Tell us what you cited


After your agent answers, report which pages it read and which it cited:


curl -s -X POST "ORIGIN/v1/feedback" \
  -H "Authorization: Bearer YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"query": "Humane AI Pin",
       "fetched": ["https://example.com/a", "https://example.com/b"],
       "cited":   ["https://example.com/a"]}'


This is how the scores learn. A page that gets read and cited scores higher for everyone next time;
a page that gets read and ignored scores lower, and so does its price (prices are simulated for now).
The response shows how much each page's score moved.



Search results come from Keenable. Scores use OpenAI models.
